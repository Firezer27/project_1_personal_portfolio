# project_1_personal_portfolio

## Project: Personal portfolio website

### What it does:

A simple website showing who I am, my skills, and my projects.

### Who uses it:

Employers and people who want to hire me.

### Problem it solves:

I have no online presence. People can't find my work.

### Features I need (MVP):

- Home page with my name and short intro
- Skills section (HTML, CSS, JavaScript)
- Projects section with 2-3 project cards
- Contact info (email + GitHub link)

### Out of scope (for now):

- Blog
- Animations
- Contact form
- Dark mode
